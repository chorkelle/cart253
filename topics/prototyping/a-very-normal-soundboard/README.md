# A Very Normal Soundboard

Charlotte Walsh

[View this project online](https://chorkelle.github.io/cart253/topics/prototyping/a-very-normal-soundboard/)

## Description

A soundboard whose buttons try to run away when you click the other buttons.

> - Inspired by the sound button from week 3.
